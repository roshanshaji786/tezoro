## Editing and rebuilding

The PDF is generated from `proposal/source/brochure.html`.

```bash
pip install playwright && playwright install chromium
cd proposal/source
python3 render.py   # writes ../Tezoro_Brand_Proposal_DARTS_AI.pdf
```

The `source/` folder also contains:
- the fonts: Cormorant Garamond, Cinzel and Inter (Inter must be installed on the system)
- the DARTS AI logo files
